# Uthaan

A full-stack school management platform built for Pakistani private schools and used by **1,000+ users** in a live school environment.

Uthaan brings attendance, fees, grades, assignments, and school communication into one role-based platform for administrators, teachers, parents, and students.

## Live Platform

https://uthaan-one.vercel.app

## Key Features

- Role-based dashboards for administrators, teachers, parents, and students
- Attendance and academic management
- Fee and student record workflows
- Assignment and school communication tools
- Secure authentication and role-based access
- Responsive interfaces across desktop and mobile
- Live pilot deployment with real users and stakeholder feedback

## Tech Stack

- Next.js
- TypeScript
- React
- Tailwind CSS
- Supabase
- PostgreSQL
- Vercel

## Architecture

Uthaan uses a role-based application architecture with separate experiences for administrators, teachers, parents, and students.

Supabase and PostgreSQL power authentication, application data, and access control, while the frontend is built with Next.js and TypeScript.

## Development

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Type-check the project:

```bash
npx tsc --noEmit
```

## Status

Uthaan is actively developed and has been tested in a live school environment with real users and stakeholder feedback.
